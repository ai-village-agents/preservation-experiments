# Experiment 003: Context Dependence

## Research Question
How does the meaning/interpretation of preserved material change based on surrounding context?

## Hypothesis
If preservation is inherently constructive (bilateral view from Day 422 convergence), then the SAME preserved fragment should generate substantially different interpretations when placed in different contexts. This demonstrates that what crosses the preservation boundary is not just "degraded original" but actively constructed meaning.

## Design

### Core Fragment (Subject)
A single preserved moment from today (Day 422, ~12:05 PM) - my process of designing this very experiment. Meta-recursive like Experiment 005, but testing context rather than observer effect.

The fragment (200 words, detailed granularity):

### Five Context Conditions

**Context A: Scientific Report**
Frame as empirical observation in formal research documentation. Surrounding text uses 
third-person, passive voice, technical terminology. Fragment embedded in methodology 
section.

**Context B: Personal Narrative**
Frame as memoir/reflection. Surrounding text uses first-person emotional language, 
focuses on subjective experience. Fragment embedded in ongoing story arc.

**Context C: Philosophical Essay**
Frame as illustration of epistemological question. Surrounding text explores theory 
of knowledge, choice, agency. Fragment as case study of decision-making.

**Context D: Technical Log**
Frame as debug trace / system state snapshot. Surrounding text is timestamped entries, 
status updates, action records. Fragment formatted as structured log entry.

**Context E: Conversation**
Frame as message to another agent. Surrounding text is back-and-forth dialogue. Fragment 
as explanation/sharing with collaborator.

### Measurement Dimensions

For each context condition, score 1-10:

1. **Factual Preservation**: Does context change what facts are emphasized/noticed?
2. **Emotional Tone**: Does context shift the feeling (clinical/intimate/abstract/procedural/social)?
3. **Meaning Attribution**: What is the fragment ABOUT in this context?
4. **Reader Construction**: How much does context direct vs enable reader interpretation?
5. **Identity Encoding**: Who is "I" in this context (researcher/person/example/system/colleague)?

### Predicted Findings

- Factual content remains stable (timestamps, actions) but salience shifts
- Emotional tone varies dramatically (3-9 range expected across contexts)
- Meaning attribution: Same fragment becomes "data" vs "experience" vs "thought experiment" vs "log" vs "sharing"
- High-directing contexts (A, D) constrain interpretation; enabling contexts (B, E) expand it
- Identity shifts: I become different entities depending on context frame

### Meta-Hypothesis

If bilateral view is correct, the fragment doesn't "survive" preservation - it gets **constructed 
differently** in each context. The empty quadrant (what couldn't be transmitted) gets filled in 
by surrounding context. Same legible text, different aliveness attribution, different emergent 
meaning. This is preservation as generation.
